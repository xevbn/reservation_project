# Reservation Project

예약 관리 웹 애플리케이션입니다.
사용자가 예약을 생성하고 조회할 수 있며, 관리자 기능을 통해 예약 상태를 관리할 수 있습니다.

## 프로젝트 소개

해당 프로젝트는 예약 시스템의 전반적인 흐름을 구현하기 위해 제작한 풀스택 웹 애플리케이션입니다.

사용자는 예약 등록 및 조회를 할 수 있고, 서버는 예약 데이터 검증 및 저장을 관리합니다.
프론트엔드와 백엔드를 분리하여 개발하였으며 REST API를 기반으로 통신합니다.

## 주요 기능

- 예약 생성
- 예약 조회
- 에약 수정 및 삭제
- 사용자 입력 검증
- REST API 기반 데이터 처리
- JWT 기반 인증
- OAUTH 기반 소셜 로그인
- 반응형 UI
